# AeroVision X

A free product launch HTML template by TemplatesJungle.com, designed for AeroVision X, a high-performance drone product.

## Included Pages

- `aerovision/index.html` - Main landing page with product highlights, specifications, gallery, safety information, and call to action
- `aerovision/product.html` - Product overview
- `aerovision/pricing.html` - Pricing plans and frequently asked questions
- `aerovision/support.html` - Support resources and contact form

## Preview Locally

No build process or package installation is required.

1. Open `aerovision/index.html` directly in a browser, or
2. Serve the project with any local static server and open the resulting URL.

The pages load Tailwind CSS and Google Fonts from external CDNs, so an internet connection is needed for the complete styling and typography when previewing locally.
