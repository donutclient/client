# Prestige Client website

A minimal, self-contained landing page for the supplied Prestige Client JAR.

## Preview

Open `index.html` in a modern browser. No build step or external assets are required.

## Included files

- `index.html` — single-screen download page
- `styles.css` — responsive styling
- `assets/favicon.svg` — browser tab icon
- `downloads/prestige-client-1.21.11-.jar` — supplied client file
